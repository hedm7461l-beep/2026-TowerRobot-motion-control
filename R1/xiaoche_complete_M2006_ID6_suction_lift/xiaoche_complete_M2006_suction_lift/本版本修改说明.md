# 本版本修改说明：吸盘升降改为C610 + M2006

## 已完成的修改

- 原来的520直流电机与第二块L298N控制逻辑已经删除。
- 新增第三套C610 + M2006，电调ID固定为6。
- CAN反馈接收范围由 `0x201～0x205` 扩展为 `0x201～0x206`。
- `0x1FF` 控制报文分配：
  - DATA[0..1]：ID5，原夹爪升降M2006。
  - DATA[2..3]：ID6，新吸盘升降M2006。
- bool12为吸盘升降上升，bool13为吸盘升降下降。
- 按住按键连续改变目标位置；松手后冻结目标并继续位置闭环与重力补偿保持。
- ID6反馈超过100ms未更新时，该路电流自动置0。
- PA5、PB10、PB11已经释放，不再用于吸盘升降。
- 已加入用户提供的14个bool手机配置文件：
  `BTMCU/调试工程_H_20260731-203123_M2006吸盘升降.pro`。

## 接线与ID

新增M2006的三相线和传感器线接新增C610；新增C610的CANH/CANL接原CAN集线器，动力正负极接电调动力电源，并把电调ID设置为6。

上电前必须把吸盘升降放在最低基准位。程序收到第一帧 `0x206` 反馈时，会把当时位置作为相对零点。

## 初次测试建议

先拆开机械负载或系好安全绳，再适当降低下列参数：

```c
#define SUCTION_LIFT_MAX_OUTPUT_DEG             800.0f
#define SUCTION_LIFT_TARGET_SPEED_DEG_PER_SEC   300.0f
#define SUCTION_LIFT_CURRENT_LIMIT              5000.0f
#define SUCTION_LIFT_GRAVITY_HOLD_CURRENT       1000.0f
```

建议第一次空载测试先把最大行程改为30°～60°、目标速度改为30°/s、电流上限改为400～600、重力补偿改为0。确认方向和反馈正常后再逐步增加。

如果上下方向相反，只修改：

```c
#define SUCTION_LIFT_UP_SIGN -1
```

不要通过交换无刷电机三相线来代替代码方向设置。
